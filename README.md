# Quest 4-Cam Volkswagen Works - Classic Air-Cooled Service Website

A professional, high-end service website built for a classic Volkswagen restoration and repair specialist ('50s–'70s air-cooled Beetles, buses, and Ghias).

## Features
- **Cinematic Classic VW Theme**: Dark garage aesthetics with vintage gold accents and background photography of classic Beetles.
- **Service Breakdown**: Clear breakdown of engine rebuilding, full restorations, electrical overhauls, and suspension work.
- **Direct Email Integration**: The consultation form instantly pre-fills and opens an email to **questforthe4cam@gmail.com** with all project and vehicle details.
- **Fully Responsive**: Optimized for phones, tablets, and desktop displays.

## How to View via GitHub Pages
1. Go to your GitHub repository **Settings**.
2. Click on **Pages** in the left sidebar.
3. Under **Build and deployment**, select `Deploy from a branch`.
4. Choose the `main` branch and `/ (root)` folder, then click **Save**.
5. Your website will be live in a minute at `https://<your-username>.github.io/<repository-name>/`!
